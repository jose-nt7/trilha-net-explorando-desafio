# 🏨 Desafio de Hospedagem em C#

Projeto desenvolvido durante a trilha **.NET da Digital Innovation One (DIO)**, com o objetivo de praticar os fundamentos da linguagem C# e a programação orientada a objetos.

## 📋 Sobre o projeto

O sistema simula a administração de reservas de um hotel, permitindo cadastrar hóspedes, configurar suítes e calcular o valor de uma hospedagem de acordo com a quantidade de diárias reservadas.

## ⚙️ Funcionalidades

- Cadastro de hóspedes.
- Cadastro e configuração de suítes.
- Verificação da capacidade máxima da suíte.
- Cálculo do valor total da hospedagem.
- Aplicação de 10% de desconto para reservas de 10 dias ou mais.

## 🛠️ Tecnologias utilizadas

- **C#**
- **.NET**
- **Programação Orientada a Objetos (POO)**
- **Git e GitHub**

## 📚 Conceitos praticados

- Classes e objetos.
- Propriedades e construtores.
- Listas e coleções.
- Métodos e encapsulamento.
- Estruturas condicionais.
- Operações com valores monetários.
- Tratamento de exceções.

## ▶️ Como executar o projeto

1. Instale o SDK do .NET.
2. Clone este repositório:

   ```bash
   git clone https://github.com/jose-nt7/trilha-net-explorando-desafio.git
   ```

3. Entre na pasta do projeto.
4. Execute o programa pelo terminal:

   ```bash
   dotnet run
   ```
